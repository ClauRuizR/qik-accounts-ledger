# Qik Ledger API

NestJS GraphQL API for the Qik Accounts & Ledger Service.

Setup, configuration, architecture, the GraphQL reference and design decisions are in the
[repository README](../../README.md).

```bash
npm run start:dev        # GraphQL on http://localhost:3000/graphql
npm test                 # unit tests
npm run test:e2e         # integration tests (needs `npm run db:up` from the repo root)
npm run migration:run    # apply migrations
npm run lint             # ESLint
```
